# 盐田卤水与结晶过程仿真系统

浏览器端盐田水文-卤水浓缩-结晶析盐仿真,TypeScript + WebGPU 计算着色器 + IndexedDB。

## 运行

```bash
npm install
npm run dev      # 开发服务器(自动选端口)
npm test         # CPU 参考引擎守恒/物理回归测试
npm run build    # 类型检查 + 生产构建
```

无 WebGPU 环境(或浏览器禁用)自动回退到 f64 CPU 参考引擎,两后端返回结构一致。

## 架构

```
src/sim/
  units.ts      波美度↔浓度查找表、蒸发公式、WGSL 常量注入(CPU/GPU 同一份表)
  field.ts      230 格滩田:9 级段(纳潮/6 蒸发/调节/3 行结晶)、242 条闸渠、坡降地形
  weather.ts    120 天×24h 确定性气象:半日潮、温湿风日照、第 70 天起 72h 特大暴雨
  engine.ts     CPU 参考引擎(f64):Jacobi 汇流、蒸发纳雨、漫顶、析盐化盐、苦卤、收盐
  shaders.ts    WGSL 计算着色器:gate→edge→cell→harvest 四 pass,公式与 engine.ts 逐式对照
  gpu.ts        WebGPU 引擎:5 个打包缓冲、双缓冲、邻接表归约、盐账归约
  runner.ts     统一入口(GPU 优先,CPU 兜底)
src/render/     Canvas 俯视渲染(浓度/盐层/标记叠加)、贴地剖面、青灰→浅红调色板
src/pages/      五个页面:滩田布局、纳潮制卤、结晶池、天气推演、收盐调度
src/db/idb.ts   IndexedDB 持久化(布局/季节/结果/计划/设置)
```

## 关键设计

- **盐账守恒**:每格分别记账溶解盐与固态盐;汇流、纳潮、排走、漫顶、收盐全部走通量恒等式。
  CPU(f64)相对误差 ~1e-15,WebGPU(f32)~1e-9,均远严于 1‰ 要求。
- **WebGPU 缓冲打包**:设备 `maxStorageBuffersPerShaderStage=10`,全部状态装入
  uniform + dyn/prev/static/edge/counter/link 共 6 个 storage,边通量独占槽位 + cell  pass 邻接表归约,避免并行读-改-写竞态。
- **闸门批式轮转(迟滞)**:下游蒸到低水位开闸补卤、到高水位关闸,保证逐级停留浓缩;
  暴雨预警关闸滞洪、排淡闸常开、预警 24h 雨量 >60mm 紧急抢收。
- **物理过程**:25°Bé 饱和后仅结晶池析盐(85% 析出/15% 留溶),雨水冲淡时盐板回溶;
  卤水龄期 ≥10 天的饱和老卤标记苦卤;漫顶/苦卤/已收标记锁存便于时间轴回放。

## 需求对照

| 需求 | 实现 |
| --- | --- |
| 实测式网格/高程埝埂/闸渠网 | 滩田布局页,可编辑池底高程与埝埂、点击闸门启闭 |

| 苦卤 >30°Bé 标记与排放 | 结晶池苦卤清单 + 苦卤排放闸 |

| ≥200 格、含三天暴雨的整季数据 | 230 格、120 天、第 70 天 72h 特大暴雨 |
| 盐账误差 ≤1‰、整季 <1 分钟 | CPU 0‰/279ms,WebGPU ~1e-9‰/约 1.2s(含每日读回) |
